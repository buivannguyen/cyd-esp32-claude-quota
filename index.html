ESP32 CYD - Claude Quota Monitor

Cắm board ESP32 CYD vào máy tính bằng cáp USB, mở trang này bằng Chrome hoặc Edge trên máy tính, rồi bấm nút bên dưới để nạp firmware trực tiếp từ trình duyệt.

Trình duyệt của bạn không hỗ trợ Web Serial. Hãy dùng Chrome hoặc Edge trên máy tính (không dùng được trên điện thoại). Trang này cần mở qua HTTPS.

Chưa có board?

Mua board ESP32 CYD (ESP32-2432S028R) tại Shopee.

Lấy Claude token:

  1. Cài Claude Code trên máy tính.
  2. Chạy lệnh claude setup-token rồi làm theo hướng dẫn để đăng nhập.
  3. Sao chép token dạng sk-ant-oat01-... hiện ra (token sống ~1 năm).

Chạy lại claude setup-token lần nữa sẽ thu hồi token cũ, nên chỉ tạo khi cần.

Sau khi nạp firmware xong:

  1. Board sẽ phát WiFi mở tên ESP32-CYD-Setup.
  2. Nối điện thoại/máy tính vào WiFi đó, trang cấu hình sẽ tự mở (hoặc vào http://192.168.4.1).
  3. Nhập tên + mật khẩu WiFi nhà và Claude token vừa lấy, bấm Lưu.
  4. Board khởi động lại và hiển thị quota Claude.

Chi tiết cách dùng và mã nguồn: github.com/buivannguyen/cyd-esp32-claude-quota
